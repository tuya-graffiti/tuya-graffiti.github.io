动态规划

发表于 2025-11-24 更新于 2025-11-30 分类于 CS ， 范式 ， 动态规划

def

Dynamic Programming ,简称DP。如果某一问题有很多重叠子问题，使用动态规划是最有效的。

所以动态规划中每一个状态一定是由上一个状态推导出来的，这一点就区分于贪心，贪心没有状态推导，而是从局部直接选最优的。

  2. 递推公式
  3. 初始化
  4. 遍历顺序
  5. 举例推导
