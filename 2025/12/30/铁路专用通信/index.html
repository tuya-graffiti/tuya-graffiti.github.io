铁路专用通信

发表于 2025-12-30 更新于 2025-12-31 分类于 通信工程 ， 铁路专用通信

0

前言

铁路调度通信系统的数字化是铁路信息化建设的基础,只有实现了数字化,才能应用于各种通信的业务接口,既能满足调度通信的需要和多种业务的接入,又能适应与铁路综合数字移动通信系统(GSM-R)的互速互通及与其数字交换机的互连。

DMIS系统是实现铁路运输调度对列车实现透明指挥、实时调整、集中管理的现代指挥管理信息系统,该系统具有实时采集列车运行及现场信号设备状态信息,实时传送到各级调度指挥中心,能完成列车运行实时追踪、自动报点、正晚点统计分析、按交车自动统计、运行图自动绘制、阶段计划自动调整、调度命令及行车计划自动下达功能,是调度指挥系统自动化的重要手段。

铁路综合数字移动通信系统(GSM-R)是国际铁路联盟为铁路专用调度通信开发的移动通信系统,它适合高速度环境下使用，可实现跨越国界的高速列车和一般列车之间的通信,能将现有的铁路通信融合到单一的网络平台，能灵活地提供专网中所需的语音调度服务,如VBS、VGCS和eM!PP等业务,是我国未来铁路移动通信系统的骨干设备。为了便于无GSM-R基础知识的读者阅读，本书第六章就GSM-R的基本工作原理进行了比较详细的论述。

1绪论

1.1 业务

传统的铁路专用通信的业务包括干、局线通信,区段通信,站场通信，无线专用通信，应急通信和列车通信,近年来铁路正在大力发展GSM-R数字移动通信系统,具体类别见表1-1。

铁路运输调度通信是铁路专用通信的重要组成部分,是直接指挥列车运行的通信设施,是铁路专用通信的主体,本书主要讨论调度通信系统。按铁路运输指挥系统分干线、局线、区段三级调度通信体系。

干线调度通信是铁道部为统一指挥各铁路局,协调完成全国铁路运输计划,在铁道部与铁路局之间设立的各种调度通信。局线调度通信是铁路局为统一指挥所属主要站段,协调完成全局运输计划,在铁路局与编组站、区段站、主要大站之间设立的各种调度通信。

表格 三层网络对比

网络 谁指挥谁？ 形状 核心设备 一句话特点
干线网 铁道部 → 铁路局 星型 Hicom调度交换机 高层指挥，全国互联
局线网 铁路局 → 各站段 星型 数字调度主机 中间枢纽，承上启下
区段网 调度员 → 本区段车站 环型（2M环） 主系统+车站分系统 一线实战，安全可靠（环不怕断）

1.2 铁路调度通信设备的发展历程

  • 考试问法：“简述调度电话的发展阶段”或“数字调度电话的特点”。
  • 你只要背：三个阶段：电子管（脉冲）→晶体管（双音频）→集成电路（数字交换）。数字化的特点：快、可靠、能开会、能管。

1.3 铁路调度通信网的网络结构

一、铁道部干线调度通信网铁道部运输指挥中心设数字调度交换机,用数字中继通道与各铁路局运输指挥中心的数字调度交换机相连,相邻铁路局的数字调度交换机之间也以数字中继通道作为直达路由,从而组成一个复合星形网络结构的于线调度通信网。

二、铁路局局线调度通信网铁路局的局线调度数字交换机用数字中继通道与各铁路站段数字调度交换机(也可利用区段数字调度设备)相连,构成一个星型网络结构的局线调度通信网。不在站段所在地的局调分机,利用区段数字调度通道或专线延伸至区段站、编组站、中间站。

三、区段调度通信网铁路站段运输指挥中心(站段调度所)设区段数字调度机(俗称主系统)，与所辖区段沿线各中间站车站数字调度机(俗称分系统),用2M数字通道呈串联型逐站相连,并由末端车站环回,组成一个2M自愈环。区段内所有调度业务(行调、货调、电调、无线列调)纳人2M数字环内,一种调度业务固定占用一个共线时隙。具体组网方式在第四章讨论。

1.4 数字调度通信设备的特点

  1. 数字传输：端到端数字化，噪声小、接续时间＜50ms。
  2. 技术先进：数字交换 + 计算机技术，模块化、分散控制。
  3. 数模兼容：支持模拟线路接入（如分叉站模拟设备），模拟回线可作数字通道备用。
  4. 多业务接入：支持语音、数据（DMIS）、图像传输，预留接口扩展。
  5. 高可靠性：1+1 热备份、自愈环组网、硬件冗余。
  6. 集中维护：网管台监控沿线分系统，支持远程诊断。

1.5 铁路综合数字移动通信网络（GSM-R）

  • 定位：铁路信息化核心，属于通信网络系统（固定 + 移动），支撑其他 5 大信息化系统（业务管理、过程控制等）。
  • 目标：实现移动信息采集 / 传输，为调度、指挥、控制提供平台，适配高速列车需求。

课后题

  1. 调度通信发展历程及技术特点答：分三阶段：
    • 1950s-1960s 末：电子管，脉冲选叫，技术简单、传输质量差。
    • 1970s 初 - 1990s 末：晶体管，双音频选叫（YD 系列），后期升级为 DC-7 程控调度（模拟，选叫 600ms），功能增多但仍属模拟通信。
    • 1990s 末 - 至今：集成电路，数字交换 + 计算机技术，数字化、综合化，选叫＜50ms，支持多业务、自愈环，兼容模拟设备。
  2. 干、局、区段调度网拓扑结构差异答：
    • 干线网：复合星形，铁道部为汇接中心，铁路局为节点，2M 数字中继连接，相邻铁路局设直达路由。
    • 局线网：星形，铁路局为中心，站段为节点，利用干调交换机或专用数字设备组网。
    • 区段网：总线型（2M 自愈环），站段为主系统，中间站为分系统，逐站串联 + 末端环回，断纤后自愈。
  3. 数字调度通信设备主要特点答：①数字传输，端到端无衰耗；②数字交换 + 计算机技术，模块化；③数模兼容，支持模拟线路备用；④多业务接入（语音、数据、图像）；⑤1+1 热备份 + 自愈环，高可靠；⑥集中网管 + 远程诊断，维护便捷。
  4. 铁路信息化主要内容答：由六大系统组成：①业务管理信息系统；②过程控制与安全保障系统；③办公信息系统；④社会化信息服务系统；⑤决策支持与综合应用系统；⑥通信网络系统（含固定通信网和移动通信网，如 GSM-R）。核心是通过信息技术实现运输生产、经营、服务现代化。

2 程控调度电话系统原理

程控调度电话系统是利用计算机及微电子等技术,实现铁路调度通信的设备采用数字编码信号选叫分机并采用程序控制技术是程控调度电话的特点。本章主要介绍程控调度电话硬件构成原理及软件结构,并对系统主要技术指标进行简要分析。

2.1 概述

关键特点（对比老式设备）

  • 选叫速度：从 6 秒缩短到 600 毫秒（眨眼功夫）；
  • 功能：支持单呼、全呼、录音、自检等，还能防杂音；
  • 适配性：能接各种铁路通信线路（铁线、铜线、电缆）。

2.1.1 整体结构

  • 核心设备：总机（带选叫箱）+ 分机；
  • 两大核心部分：
    • 选叫部分：总机对分机的选叫及检测,同时也完成分机摘/放机信号的接收及显示等；包括总分机中的信号发送及信号接收电路以及总机中的专用微型机、分机中的专用单片微信机等。专用微型机还完成其他功能及控制作用。
    • 通话部分：总机的送受话放大器和踏键、分机的话机。

2.1.2 选叫信号：怎么精准 “喊到” 目标分机？

选叫信号是 “数字调频信号”，可以理解为 “带编码的声波”，规则如下：

  • 编码结构：先导码（标志码，比如 0CAH）+ 分机码（比如单呼用 C₈⁴组合码）；
  • 频率规则：“1” 对应 1300Hz，“0” 对应 2000Hz，信号传输速度 100bit/s；
  • 特点：抗干扰强，能在长距离线路上稳定传输。

2.2 硬件构成

2.2.1 系统整体构成

  • 核心设备：总机（含控制盘、整配盘、通话盘、电源盘、告警盘）与分机，总机需搭配选叫箱才能正常工作。
  • 功能划分：选叫部分（完成总机对分机的选叫、检测及分机摘 / 放机信号处理，含信号发送 / 接收电路、专用微机）和通话部分（含总机送 / 受话放大器、踏键及分机话机）。

2.2.2 总机核心硬件

  • 控制盘（专用微型机）：双处理机结构（8085A 主机 + 8748 从机），主机负责编码、译码、功能控制，从机负责调制解调；核心芯片含程序存储器（2732）、数据存储器接口（8155）、键盘 / 显示接口（8279-5）、台间联络接口（8251A）等。
  • 整配盘：实现阻抗匹配、二 / 四线转换、信号放大及发送 / 接收信号转换，适配不同线路特性（铁线、铜线、电缆）。
  • 通话盘：含送话放大器（TA7668AP）和受话放大器（TA7240AP），具备自动电平调整（AGC）、高频提升、静噪功能，保证通话音质。

2.2.3 分机硬件构成

  • 核心：专用单片机（80C39/80C48）+ EPROM（27C16）+ 三态锁存器（74HC373），实现信号接收、解调、响应及发码功能。
  • 关键接口：通过 I/O 口实现用户监测、振铃控制、回铃信号发送、摘 / 放机信号处理，支持本地地址编码设置。

2.3 软件结构

1. 软件设计原则

  • 主机软件：按中断方式设计，优先级为 RST7.5（从机通信）＞RST6.5（台间联络）＞RST5.5（键盘 / 显示）。
  • 从机软件：按查询方式设计，核心完成软件调制解调及与主机的数据交换。

2. 核心软件模块

  • 主机软件：初始化模块（设置计数器、标志位、中断入口地址、清显示、开中断）、键盘分析模块（按键编码读取、合法性判断、功能映射）、选叫分机模块（分机码计算、标志设置、发码控制）、RST7.5 中断服务模块（处理发送 / 接收 / 定时 / 自检中断）。
  • 从机软件：调制模块（将二进制码转换为 FSK 信号，添加起始位 / 结束位）、解调模块（通过过零检测还原二进制码，去掉冗余位）、定时控制模块（发码后等待回执信号的定时）。

3. 核心功能实现流程

  • 单呼流程：按键触发→编码→发先导码 + 分机码→等待回铃码→收到回铃码点亮指示灯，未收到则重发 3 次→故障提示。
  • 全呼流程：按全呼键→发先导码 + 全呼码→等待回铃码→收到回铃码点亮指示灯，未收到则重发 3 次→故障提示。
  • 其他功能流程：依次选叫（逐次呼叫指定分机）、台间联络（通过 8251A 实现串行通信）、自检及分机检测（在线诊断设备状态）。

2.4 系统主要技术指标及分析

1. 传输适配指标

  • 适用线路：4.0mm 铁线（100km 区段）、3.0mm 铜线（400km 区段）、0.9mm 加感电缆等，支持载波遥控通路；传输通路定位衰耗≤22dB（800Hz），最大衰耗≤30dB（800Hz）。
  • 音频性能：远端分机讲话扬声器输出功率≥100mW（20dB），近端≤350mW（25dB）；300Hz 与 3400Hz 电平差≤10dB，杂音防卫度≥33dB。

2. 信号传输指标

  • 选叫信号：FSK 调制，传号频率 1300Hz，空号频率 2000Hz，传信率 100bit/s，偏移率 7，采用异步传输；选叫码由先导码（OCAH）+ 分机码组成，有效位 16 位（偶校验）。
  • 电平设计：发送电平（52±2）dB，接收灵敏度 - 36dB（1400Ω 阻抗下 20mV），确保恶劣环境下可靠接收。

3. 阻抗匹配指标

  • 总机输入阻抗：适配不同线路（600±15%Ω/1400±10%Ω，800Hz），减少信号损耗。
  • 分机输入阻抗：未摘机时（2000Hz）≥30kΩ，摘机时（800Hz）≥18kΩ，降低传输衰耗。

4. 其他关键指标

  • 选叫时长：单次选叫（含等待回铃码）约 620ms，三次重发最长 2320ms；分机耗电量：平时≤10mA，响铃时≤100mA。
  • 功能扩展：选叫号码可扩充至 70 个，预留接口支持功能升级。
