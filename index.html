4 铁路调度通信网

一、核心内容总结

1. 干线调度通信网

  • 网络组成：铁道部 Hicom 382 为汇接中心，各铁路局 Hicom 372 通过 2M 数字中继连接，相邻铁路局设直达路由，构成复合星形网。
  • 编号与呼叫：全路统一五位码（ABCDE，AB = 局向号，CDE = 用户号），调度台单键直呼，网内用户直拨五位码，调度员可强插、全呼 / 组呼。
  • 同步：主从同步，铁道部 SPC 为主时钟，Hicom 382 为第一从时钟（双备份），铁路局 Hicom 372 从第一从时钟提取时钟，故障时启用自身时钟（精度 ±1×10⁻⁶）。
  • 接口与信令：局间用 30B+D 数字接口，CorNET 共路信令（覆盖 Q.930/Q.931 标准），支持遇忙转移、会议电话、强拆等调度功能。

2. 局线调度通信网（三种组网方式）

组网方式 结构 优点 缺点
用户线方式 铁路局 Hicom 372 直接放号到站段（PCM + 环路设备） 简单 占干调端口 / 通道，灵活性差，难延伸至中间站
中继线方式一 铁路局 Hicom 372 + 站段 Hicom 315，2M 中继星形组网 网管 / 信令统一 难延伸至中间站，不兼容模拟区段，浪费区段设备
中继线方式二 铁路局专用通信主系统 + 站段区段数字设备，2M 中继星形组网 兼容模拟区段，利用既有设备 需信令转换（局 - 区段用 DSS1，区段 - 中间站用内部信令）
  • 编号：五位码（同干线），中间站模拟用户需经局调台转接。
  • 同步：铁路局局调交换机为第一从时钟（从干调 Hicom 372 提取），站段交换机从第一从时钟同步。

3. 区段调度通信网

  • 核心特点：①数字共线型（调度员 - 车站值班员一点对多点，复用时隙）；②2M 自愈环（主用 + 备用 2M，断纤后迂回）。
  • 组网关键：
    • 自愈环容量：稳定串接 50-64 个分系统，实际按 1-2 个行车调度区段组网（避免过长影响可靠性）。
    • 特殊场景处理：
      • 枢纽列调：星型汇接（A/B 方向纳入主干环，C 方向自建支环，D 方向模拟接入）。
      • 分支线：模拟分支用模调接口，数字分支自建支环接入主干环。
      • 无 ONU 站：邻近站延伸 2B+D 接口，或用数字倍增器（区间实回线主备）。
  • 时隙分配：PCM 30/32 帧，TS₀（同步）、TS₁₆（信令），可用 26 个时隙；信令占 TS₂₈-TS₃₁（3-4 个），调度业务（行调 / 货调等）各占 1 个共线时隙，站间业务占 2-3 个时隙（分段复用）。

二、课后题答案（复习思考题）

  1. 局线调度网组网方式及优缺点答：三种方式：
    • 用户线方式：优点是简单；缺点是占用干调端口和长途通道，灵活性差，难延伸至中间站。
    • 中继线方式一（Hicom 系列）：优点是网管和信令统一；缺点是难延伸至中间站，不兼容模拟区段，浪费既有区段设备。
    • 中继线方式二（专用通信 + 区段设备）：优点是兼容模拟区段，利用既有设备，灵活延伸至中间站；缺点是需信令转换（局 - 区段用 DSS1，区段 - 中间站用内部信令）。
  2. 区段网 2M 自愈环优点答：①断纤自愈：任意点断裂后，通过备用 2M 迂回，不中断通信；②双重保护：即使传输网故障，区段自愈环仍可独立保障调度业务；③提升可靠性：配合设备 1+1 热备份，满足铁路调度 “不间断” 需求；④简化维护：无需人工倒接，自动恢复。
  3. 区段网 PCM 30/32 时隙分配答：①TS₀：同步时隙（偶帧传帧同步码 0011011，奇帧传失步告警 A₁）；②TS₁₆：标志信号时隙（F₀帧传复帧同步码 0000，F₁-F₁₅帧传 30 路话路信令）；③可用话路时隙：TS₁-TS₁₅、TS₁₇-TS₃₁（共 30 个）；④信令控制时隙：占用 TS₂₈-TS₃₁（3-4 个）；⑤业务时隙：行调 / 货调 / 电调 / 无线列调各占 1 个共线时隙，站间业务占 2-3 个时隙（分段复用），剩余时隙可扩展公务电话、应急通信等。

第五章 DMIS 系统

一、核心内容总结

1. DMIS 系统概述

  • 定义：铁路运输调度指挥管理信息系统（Dispatch Management Information System），替代传统手工调度，实现 “三级（部 / 局 / 站段）分散控制、集中管理”。
  • 发展：1996 年立项，“九五” 一期建 545 个车站采集网，“十五” 二期全面推广，核心是实时采集 / 处理列车运行信息，支撑调度自动化。
  • 特点：高技术性（计算机 / 网络 / 多媒体）、封闭网络（闭环控制）、独立性（专注行车指挥）、实时性（信息捕捉 - 处理 - 显示无延迟）、高可靠性（容错设计）、安全性（故障 - 安全、防病毒）。

2. DMIS 系统结构

  • 总体结构：铁道部 - 铁路局 - 站段三级广域网，各层级以交换机为核心组建局域网，路由器互连。
  • 各层级硬件：
    • 铁道部：高性能服务器、工作站、大屏投影，接收全路实时信息。
    • 铁路局：双服务器 + 磁盘阵列（集群，负载均衡 / 热备）、双交换机（双网冗余）、行调台、网管工作站、大屏投影。
    • 站段：服务器、行调台、路由器，连接基层采集点。
    • 基层网：DMIS 分机（信息采集 / 控制）、电务监测机、车务终端（邻站显示 / 调度命令接收）、路由器 / 集线器。

3. DMIS 系统功能与作用

  • 铁道部：宏观监视全路列车运行（正点率 / 密度）、重点列车追踪、分界口统计。
  • 铁路局：
    1. 宏观显示：正点率（客车＞98%/80-98%/＜90% 三色显示）、列车密度（图定利用率＞90%/80-90%/＜80% 三色）。
    2. 实时监视：枢纽 / 编组站 / 客站 / 分界口列车位置、信号状态。
    3. 运行图管理：自动绘制计划 / 实际运行图，支持打印。
    4. 分界口管理：交接列车统计、正晚点报告、历史查询。
    5. 调度命令下达：通过网络直传车站，替代人工电话。
  • 站段：实时监视辖区列车 / 信号状态、车次号管理（人工输入 + 无线校核）、自动报点、运行图自动生成、调度命令接收 / 打印。
  • 基层网：信息采集（列车到发 / 信号状态）、车次号输入 / 修正、无线车次号校核、站间透明显示。

4. 计算机辅助行车调度系统（CAD）

  • 目的：减少调度员事务性工作（收点 / 画图）、提供计划调整决策支持、自动统计列车运行指标。
  • 结构：实际运行图管理（存储 / 查询 / 打印）、列车运行调整（自动 / 手动调整 4h 货运 / 8h 客运计划）、运行统计（正晚点 / 平均速度）、共享动态数据库（支撑多区段协调）。

5. 调度监督与调度集中系统

  • 定义：利用遥测 / 遥信 / 遥控监控车站信号和列车运行，调度集中在监督基础上增加 “控制” 功能。
  • 功能：列车状态显示、车次跟踪、行车计划管理、区间信息采集、控制（人工 / 存储 / 自动控制）。
  • 控制方式：
    • 人工控制：实时输入命令，无排队，适合特殊情况。
    • 存储控制：预先输入命令序列，系统自动检查时机执行（车流稳定时用）。
    • 自动控制：按阶段计划自动办理进路，依赖计划系统。
    • 站控 / 遥控：车站值班员 / 调度员控制，需授权切换。

二、课后题答案（复习思考题）

  1. DMIS 系统的特点答：①高技术性：融合计算机、网络、多媒体、远程控制技术；②封闭网络：信息采集 - 处理 - 控制闭环，自成体系；③独立性：专注行车指挥，与其他信息化系统并行；④实时性：信息捕捉 - 传输 - 显示无延迟，循环执行；⑤高可靠性：容错设计，设备冗余（双服务器 / 双交换机）；⑥安全性：故障 - 安全，防非法入侵 / 病毒，数据备份；⑦可用性：故障自动切换，支持接口兼容；⑧操作简便：友好人机界面，软件实用。
  2. DMIS 各层之间的通信方式答：三级网络通过 “局域网 + 广域网” 互连：①铁道部 - 铁路局：专用数字通道（如 DDN），路由器互连，TCP/IP 协议，传输全路实时信息；②铁路局 - 站段：专用数字通道（2M），路由器互连，传输局内调度命令 / 运行图数据；③站段 - 基层网：2M 数字通道或 V.35 接口，传输采集的列车到发 / 信号状态信息，采用 HDLC 协议保障可靠传输。
  3. DMIS 系统的功能作用答：核心是实现行车调度自动化，具体：①实时监视列车运行（位置 / 信号状态）；②自动统计正点率 / 密度，支撑宏观决策；③自动绘制运行图，替代人工画图；④调度命令数字化下达，提高效率；⑤车次号自动跟踪 + 校核，减少人工误差；⑥站间透明显示，帮助车站值班员提前准备接发车；⑦历史数据存储，支持事故分析 / 工作总结。
  4. 计算机辅助行车调度系统（CAD）主要功能答：①实际运行图管理：存储 / 显示 / 查询 / 打印历史实际运行图，人工补录故障时的列车到发信息；②列车运行调整：自动铺划 4h 货运 / 8h 客运计划，支持人工手动调整，提供计划与实际对比；③运行统计：计算列车正晚点时分、平均速度（旅行 / 技术速度），生成统计报表；④共享动态数据库：存储车次跟踪 / 邻区段协调数据，支撑多区段协同调度。
  5. 调度监督与调度集中系统主要功能答：①显示功能：列车运行位置、信号机状态、道岔位置、股道占用情况；②车次跟踪：自动 / 人工关联车次与列车位置；③行车计划：接收 / 显示日班计划 / 阶段计划；④控制功能：人工（实时命令）、存储（预存命令序列）、自动（按计划）办理进路，支持站控 / 遥控切换；⑤维护功能：设备状态监测、故障告警、历史状态回放；⑥接口功能：与 DMIS/TMIS 系统交互数据。
  6. 调度监督与调度集中系统控制方式特点及原理答：
    • 人工控制：特点是实时性强、无排队，适合特殊情况；原理是调度员手动输入命令，系统立即检查联锁条件（无敌对进路 / 信号），满足则执行，不满足则告警。
    • 存储控制：特点是自动化程度高，适合车流稳定场景；原理是调度员预存命令序列，系统按顺序模拟执行（假锁闭），检查时机（无干扰），满足则执行，不满足则等待。
    • 自动控制：特点是完全依赖计划，效率最高；原理是计划系统按阶段计划生成进路命令，系统转换命令后检查时机，自动执行，无需人工干预。
    • 站控 / 遥控：特点是权限可切换，灵活适配现场需求；原理是车站申请站控时，调度员授权后，车站值班员通过控制台控制；调度员需遥控时，车站授权后，调度员通过 CTC 控制，二者互斥。

第六章 铁路综合数字移动通信系统（GSM-R）

一、核心内容总结

1. GSM-R 发展概述

  • 背景：铁路提速（120-250km/h）、客运专线建设需求，替代模拟无线列调（单信道、干扰大、难支持数据业务）。
  • 定义：基于 GSM Phase 2+，增加调度功能（VGCS/VBS/eMLPP），适配高速环境，国际铁路联盟（UIC）推荐的铁路专用移动通信系统。
  • 发展历程：
    1. 标准制定（1993-1995）：UIC 与 ETSI 合作，将铁路调度需求纳入 GSM Phase 2+。
    2. 试验阶段（1997-2000）：法 / 德 / 意高速线测试，验证可靠性 / 兼容性。
    3. 工程实施（1999 - 至今）：瑞典 Oresund 大桥首建商用网，德 / 瑞 / 西等国推广，我国 2000 年确定以 GSM-R 为铁路移动通信方向。
  • 业务模型：GSM 业务（电信终端 / 承载）+ 语音调度业务（eMLPP/VGCS/VBS）+ 铁路应用（功能寻址 / 位置寻址 / 列车控制）。

2. 铁路数字移动通信原理

  • 覆盖方式：
    • 面状覆盖：正六边形小区，频率复用（簇大小 N=i²+ij+j²，如 N=3/4/7），适用于站场 / 枢纽。
    • 线状覆盖（铁路专用）：圆形小区，沿铁路按 2/3/4 小区一组复用频率，重叠区宽度按 C/I≥9dB 设计，保障高速列车切换不中断。
  • 无线信道特性：
    • 传播损耗：自由空间损耗（PL=32.4+20lgd+20lgf）、多径衰落（瑞利衰落，用分集接收 / 均衡克服）。
    • 干扰：同频干扰（用定向天线 / 优化复用距离）、邻道干扰（用滤波器 / 合理信道分配）。
  • 传输技术：
    • 调制：GMSK（高斯滤波最小移频键控），BT=0.3，速率 270.833kbit/s，频谱效率高。
    • 分集接收：空间分集（多天线，间隔半波长）、频率分集（多载波）、时间分集（块交织），提高接收信噪比。
    • 信道均衡：自适应均衡器（横向 / 判决反馈），克服多径导致的码间干扰（ISI）。
    • 不连续传输（DTX）：话音激活时 13kbit/s，非激活时 500bit/s（传舒适噪声参数），降低干扰 / 节省功耗。
  • 信息处理：
    • 话音编码：RPE-LTP（规则脉冲激励长期预测），13kbit/s，MOS 分 3.5+，平衡质量与速率。
    • 加密：A5 算法生成伪随机序列，与信息比特异或，保障无线传输安全。

3. GSM-R 业务

  • 承载业务：无限制数据（UDI）、3.1kHz 音频、分组组装 / 分拆（PAD）、分组业务，支撑低层（1-3 层）信号传输。
  • 终端业务：
    • 语音：电话、紧急呼叫（无需 IMSI，优先级最高）。
    • 短消息：点对点（MO/PP/MT/PP，160 字符）、小区广播（93 字符，无确认）。
    • 传真：3 类传真（语音 / 传真交替、自动传真）。
    • 调度业务：VGCS（语音组呼，半双工，组内单用户讲话）、VBS（语音广播，仅主叫讲话）。
  • 补充业务：
    • eMLPP（增强多优先级与强拆，7 级优先级，高优先级可强拆低优先级）。
    • 号码识别：CLIP（主叫显示）、CLIR（主叫限制）、CoLP（被叫显示）、CoLR（被叫限制）。
    • 呼叫转移：无条件 / 遇忙 / 无应答 / 不可达前转。
    • 铁路特定业务：功能寻址（按功能号呼叫，如 “司机” 而非终端号）、基于位置的寻址（按列车位置路由至对应调度员）、铁路紧急呼叫（停止指定区域铁路活动）。

4. GSM-R 网络结构和功能

  • 网络子系统（NSS）：
    • MSC（移动交换中心）：核心，处理呼叫 / 切换 / 位置更新，含 GMSC（网关 MSC，路由查询）。
    • HLR（归属位置寄存器）：存储用户静态数据（IMSI/MSISDN/ 业务权限）。
    • VLR（拜访位置寄存器）：存储漫游用户动态数据（TMSI / 位置区）。
    • AuC（鉴权中心）：生成鉴权三参数组（RAND/SRES/Kc），保障用户身份合法。
    • EIR（设备识别寄存器）：存储 IMEI，分黑白灰名单，禁止非法设备接入。
    • GCR（组呼寄存器）：存储 VGCS/VBS 组 ID / 小区列表，支撑调度组呼。
  • 基站子系统（BSS）：
    • BTS（基站收发信机）：与 MS 通信，负责调制 / 解调 / 功率控制，含 TRX（收发信机，管理 1 个 TDMA 帧 8 个信道）、BCF（基站控制功能，Abis 接口管理）。
    • BSC（基站控制器）：管理多个 BTS，负责无线资源分配（信道 / 功率）、切换控制、业务集中。
    • TRAU（速率适配单元）：13kbit/s→64kbit/s PCM，适配固定网速率。
  • 操作维护子系统（OSS）：OMC-R（管理 BSS）、OMC-S（管理 NSS），实现配置 / 性能 / 故障 / 安全管理。
  • 接口协议：
    • Um 接口（MS-BTS）：GMSK 调制，LAPDm 协议（第二层），RR/MM/CM 子层（第三层）。
    • Abis 接口（BTS-BSC）：PCM 传输，LAPD 协议，支持无线信令 / OML 链路。
    • A 接口（BSC-MSC）：2M PCM，No.7 信令（MAP 协议），传递呼叫 / 位置更新信令。

5. GSM-R 识别码和寻址

  • 核心识别码：
    • IMSI（国际移动用户识别码）：MCC（国家码，中国 460）+MNC（网络码）+MSIN（用户识别），全球唯一。
    • MSISDN（移动用户 ISDN 号码）：CC（国家码）+NDC（国内目的地码）+SN（用户号码），对外拨号用。
    • IMEI（国际移动设备识别码）：TAC（型号批准码）+FAC（工厂码）+SNR（序列号）+SP（备用），标识设备合法性。
    • LAI（位置区识别码）：MCC+MNC+LAC（位置区码），用于位置更新。
  • 寻址方式：
    • 功能寻址：按功能号（如 “XX 次列车司机”）呼叫，通过 HLR 关联功能号与终端，实现功能与终端解耦。
    • 基于位置的寻址：按 MS 当前位置（小区 / 轨道电路）路由呼叫，如司机呼叫→当前区段调度员，需外部位置信息（GPS / 轨道电路）支撑。

二、课后题答案（复习思考题）

（注：原文档第六章复习思考题未完全列出，以下为核心题目及答案）

  1. GSM-R 与传统模拟无线列调的差异答：①技术体制：GSM-R 是数字系统，基于 GSM Phase 2+，支持多业务；模拟列调是单信道模拟系统，仅支持语音。②业务能力：GSM-R 支持语音 / 数据 / 短消息 / VGCS/VBS，模拟列调仅支持简单调度语音。③抗干扰：GSM-R 用数字调制 / 加密 / 分集，干扰小；模拟列调同频干扰严重。④兼容性：GSM-R 支持跨国 / 高速列车，模拟列调无兼容性。⑤扩展性：GSM-R 可平滑升级至 UMTS，模拟列调无扩展空间。
  2. GSM-R 中 GMSK 调制的特点答：①高斯滤波：BT=0.3，频谱滚降快，邻道干扰小；②恒包络：可使用高效率 C 类功放，降低设备功耗 / 体积；③速率：270.833kbit/s，适配 GSM 帧结构（每帧 8 时隙，每时隙 156.25bit）；④解调简单：无需线性功放，硬件实现成本低，适合移动终端。
  3. VGCS 与 VBS 的区别答：①讲话权限：VGCS 中组内用户可申请讲话（同一时间仅 1 人）；VBS 中仅主叫可讲话，组内用户无讲话权限。②业务场景：VGCS 用于调度协作（如司机 - 调度员 - 车站值班员）；VBS 用于单向通知（如调度员向多列车广播指令）。③信令交互：VGCS 需处理用户讲话申请 / 释放；VBS 无需，仅主叫发送，用户接收。
  4. GSM-R 网络中 HLR 与 VLR 的作用及数据差异答：①HLR：归属位置寄存器，存储用户静态数据（IMSI/MSISDN/ 业务权限 /eMLPP 优先级 / VGCS 组 ID），永久保存，全球唯一；作用是提供用户归属信息，支撑漫游时的呼叫路由 / 业务授权。②VLR：拜访位置寄存器，存储用户动态数据（TMSI / 位置区 / 漫游号 MSRN / 临时鉴权参数），用户离开后删除；作用是支撑本地呼叫处理 / 位置更新 / 切换，减少 HLR 查询次数，提高效率。

第七章 GSM-R 在铁路无线通信中的应用

一、核心内容总结

1. 功能寻址

  • 定义：按用户 “功能角色”（如 “XX 次列车司机”“XX 站值班员”）而非终端号码呼叫，功能号与终端解耦，终端更换不影响功能呼叫。
  • 实现原理：①HLR 中存储 “功能号 - IMSI” 映射关系；②主叫拨打功能号→MSC 查询 HLR→获取对应 IMSI→路由至目标终端；③功能号可动态注册 / 注销（如司机换班时更新映射）。
  • 应用场景：调度员呼叫特定列车司机、车站值班员呼叫邻站值班员，无需记忆终端号码，适配铁路人员流动性强的特点。

2. 基于位置的寻址

  • 定义：根据 MS 当前位置（如所在小区、轨道区段），自动路由呼叫至 “与位置关联的目标”，无需人工选择被叫。
  • 实现方式：
    1. 基于小区的路由：MS 所在小区 ID→MSC 查询位置数据库→关联对应调度员 / 车站（如小区 1→XX 区段调度台）。
    2. 基于外部位置的路由：通过 GPS / 轨道电路 / 查询应答器获取 MS 精确位置→传递至 MSC→路由至对应目标（如列车在 K100+500→呼叫 K100 区段防护员）。
  • 应用场景：司机呼叫调度员（自动路由至当前区段调度台）、区间作业人员呼叫车站（自动路由至最近车站值班员），减少人工操作，提高应急响应速度。

3. 无线列调

  • 定位：GSM-R 替代传统模拟无线列调（A/B/C 制式），成为铁路无线调度核心，支持列车 - 调度员 - 车站 - 作业人员全场景通信。
  • 功能升级：
    • 语音调度：VGCS 组呼（司机 - 调度员 - 车站三方协作）、VBS 广播（调度员向多列车发布指令）。
    • 数据传输：无线车次号、列车尾部风压、轴温检测数据，替代模拟列调的数话同传（减少信道占用）。
    • 应急通信：铁路紧急呼叫（优先级最高，停止指定区域作业）、区间作业人员移动通信（替代区间通话柱）。
  • 优势：①多信道：克服模拟单信道干扰问题；②高速适配：支持 250km/h 以上列车，切换不中断；③多业务：语音 + 数据融合，支撑调度自动化。

4. 调度数据和旅客服务信息传输通道

  • 调度数据传输：
    • 内容：DMIS 数据（列车运行计划 / 调度命令）、CTCS 数据（列车控制信息，如 ETCS-2 级车地通信）、设备监控数据（信号 / 电力设备状态）。
    • 通道：利用 GSM-R 电路域（64kbit/s）或分组域（GPRS），保障实时性（时延＜100ms）、可靠性（误码率＜10⁻⁶）。
  • 旅客服务信息传输：
    • 内容：车内 WiFi、旅客信息显示（到站时间 / 车次）、票务查询 / 订餐服务。
    • 通道：GPRS/EDGE（分组域），支撑宽带数据传输，带宽按需分配，提升旅客体验。
  • 关键技术：QoS 保障（调度数据优先级高于旅客数据）、冗余通道（主备信道，断道后切换）、安全加密（防止数据篡改 / 泄露）。

二、课后题答案（复习思考题）

  1. 功能寻址在铁路中的应用价值答：①降低操作复杂度：调度员 / 司机无需记忆终端号码，仅需拨打功能号（如 “XX 次司机”），适配铁路人员流动性强的场景；②提高业务连续性：终端故障 / 更换时，仅需在 HLR 更新 “功能号 - IMSI” 映射，无需通知所有关联用户；③支撑灵活调度：临时调整功能角色（如替班司机）时，快速注册新功能号，不影响正常调度。
  2. 基于位置的寻址如何提升铁路调度效率答：①减少人工干预：司机 / 作业人员呼叫时，系统自动根据位置路由至对应调度员 / 车站，无需人工选择被叫，降低操作失误；②加快应急响应：事故 / 故障时，MS 自动上报位置并路由至最近应急人员，缩短呼叫建立时间；③适配动态场景：列车高速移动中，位置实时更新，确保呼叫始终路由至当前责任主体（如跨区段时自动切换调度台），避免错呼。
  3. GSM-R 无线列调相比传统模拟无线列调的优势答：①技术体制：数字系统，抗干扰能力强（同频干扰用定向天线 / 频率复用克服），模拟列调单信道易受干扰；②业务能力：支持语音（VGCS/VBS）+ 数据（车次号 / 风压）融合，模拟列调仅支持简单语音；③高速适配：支持 250km/h 以上列车，切换成功率＞99.9%，模拟列调在高速下通信中断；④扩展性：可平滑升级至 GPRS/UMTS，支撑未来 CTCS-3 级列车控制，模拟列调无扩展空间。
  4. GSM-R 如何保障调度数据传输的可靠性答：①通道冗余：采用主备 2M 数字通道，断道后自动切换，无中断；②QoS 保障：调度数据（如 CTCS 指令）优先级设为最高，抢占低优先级业务（如旅客 WiFi）资源；③差错控制：采用前向纠错（FEC）+ 自动重传（ARQ），误码率＜10⁻⁶；④安全加密：A5 算法加密无线传输，IPSec 加密分组域数据，防止数据篡改 / 泄露；⑤网络冗余：MSC/BSC 采用 1+1 热备份，基站采用自愈环组网，设备故障不影响整体传输。

前言

铁路调度通信系统的数字化是铁路信息化建设的基础,只有实现了数字化,才能应用于各种通信的业务接口,既能满足调度通信的需要和多种业务的接入,又能适应与铁路综合数字移动通信系统(GSM-R)的互速互通及与其数字交换机的互连。

DMIS系统是实现铁路运输调度对列车实现透明指挥、实时调整、集中管理的现代指挥管理信息系统,该系统具有实时采集列车运行及现场信号设备状态信息,实时传送到各级调度指挥中心,能完成列车运行实时追踪、自动报点、正晚点统计分析、按交车自动统计、运行图自动绘制、阶段计划自动调整、调度命令及行车计划自动下达功能,是调度指挥系统自动化的重要手段。

铁路综合数字移动通信系统(GSM-R)是国际铁路联盟为铁路专用调度通信开发的移动通信系统,它适合高速度环境下使用，可实现跨越国界的高速列车和一般列车之间的通信,能将现有的铁路通信融合到单一的网络平台，能灵活地提供专网中所需的语音调度服务,如VBS、VGCS和eM!PP等业务,是我国未来铁路移动通信系统的骨干设备。为了便于无GSM-R基础知识的读者阅读，本书第六章就GSM-R的基本工作原理进行了比较详细的论述。

1绪论

1.1 业务

传统的铁路专用通信的业务包括干、局线通信,区段通信,站场通信，无线专用通信，应急通信和列车通信,近年来铁路正在大力发展GSM-R数字移动通信系统,具体类别见表1-1。

铁路运输调度通信是铁路专用通信的重要组成部分,是直接指挥列车运行的通信设施,是铁路专用通信的主体,本书主要讨论调度通信系统。按铁路运输指挥系统分干线、局线、区段三级调度通信体系。

干线调度通信是铁道部为统一指挥各铁路局,协调完成全国铁路运输计划,在铁道部与铁路局之间设立的各种调度通信。局线调度通信是铁路局为统一指挥所属主要站段,协调完成全局运输计划,在铁路局与编组站、区段站、主要大站之间设立的各种调度通信。

1.2 铁路调度通信设备的发展历程

  • 考试问法：“简述调度电话的发展阶段”或“数字调度电话的特点”。
  • 你只要背：三个阶段：电子管（脉冲）→晶体管（双音频）→集成电路（数字交换）。数字化的特点：快、可靠、能开会、能管。

1.3 铁路调度通信网的网络结构

一、铁道部干线调度通信网铁道部运输指挥中心设数字调度交换机,用数字中继通道与各铁路局运输指挥中心的数字调度交换机相连,相邻铁路局的数字调度交换机之间也以数字中继通道作为直达路由,从而组成一个复合星形网络结构的于线调度通信网。

二、铁路局局线调度通信网铁路局的局线调度数字交换机用数字中继通道与各铁路站段数字调度交换机(也可利用区段数字调度设备)相连,构成一个星型网络结构的局线调度通信网。不在站段所在地的局调分机,利用区段数字调度通道或专线延伸至区段站、编组站、中间站。

三、区段调度通信网铁路站段运输指挥中心(站段调度所)设区段数字调度机(俗称主系统)，与所辖区段沿线各中间站车站数字调度机(俗称分系统),用2M数字通道呈串联型逐站相连,并由末端车站环回,组成一个2M自愈环。区段内所有调度业务(行调、货调、电调、无线列调)纳人2M数字环内,一种调度业务固定占用一个共线时隙。具体组网方式在第四章讨论。

1.4 数字调度通信设备的特点

  1. 数字传输：端到端数字化，噪声小、接续时间＜50ms。
  2. 技术先进：数字交换 + 计算机技术，模块化、分散控制。
  3. 数模兼容：支持模拟线路接入（如分叉站模拟设备），模拟回线可作数字通道备用。
  4. 多业务接入：支持语音、数据（DMIS）、图像传输，预留接口扩展。
  5. 高可靠性：1+1 热备份、自愈环组网、硬件冗余。
  6. 集中维护：网管台监控沿线分系统，支持远程诊断。

1.5 铁路综合数字移动通信网络（GSM-R）

  • 定位：铁路信息化核心，属于通信网络系统（固定 + 移动），支撑其他 5 大信息化系统（业务管理、过程控制等）。
  • 目标：实现移动信息采集 / 传输，为调度、指挥、控制提供平台，适配高速列车需求。

课后题

  1. 调度通信发展历程及技术特点答：分三阶段：
    • 1950s-1960s 末：电子管，脉冲选叫，技术简单、传输质量差。
    • 1970s 初 - 1990s 末：晶体管，双音频选叫（YD 系列），后期升级为 DC-7 程控调度（模拟，选叫 600ms），功能增多但仍属模拟通信。
    • 1990s 末 - 至今：集成电路，数字交换 + 计算机技术，数字化、综合化，选叫＜50ms，支持多业务、自愈环，兼容模拟设备。
  2. 干、局、区段调度网拓扑结构差异答：
    • 干线网：复合星形，铁道部为汇接中心，铁路局为节点，2M 数字中继连接，相邻铁路局设直达路由。
    • 局线网：星形，铁路局为中心，站段为节点，利用干调交换机或专用数字设备组网。
    • 区段网：总线型（2M 自愈环），站段为主系统，中间站为分系统，逐站串联 + 末端环回，断纤后自愈。
  3. 数字调度通信设备主要特点答：①数字传输，端到端无衰耗；②数字交换 + 计算机技术，模块化；③数模兼容，支持模拟线路备用；④多业务接入（语音、数据、图像）；⑤1+1 热备份 + 自愈环，高可靠；⑥集中网管 + 远程诊断，维护便捷。

2 程控调度电话系统原理

程控调度电话系统是利用计算机及微电子等技术,实现铁路调度通信的设备采用数字编码信号选叫分机并采用程序控制技术是程控调度电话的特点。本章主要介绍程控调度电话硬件构成原理及软件结构,并对系统主要技术指标进行简要分析。

2.1 概述

关键特点（对比老式设备）

  • 选叫速度：从 6 秒缩短到 600 毫秒（眨眼功夫）；
  • 功能：支持单呼、全呼、录音、自检等，还能防杂音；
  • 适配性：能接各种铁路通信线路（铁线、铜线、电缆）。

2.1.1 整体结构

  • 核心设备：总机（带选叫箱）+ 分机；
  • 两大核心部分：
    • 选叫部分：总机对分机的选叫及检测,同时也完成分机摘/放机信号的接收及显示等；包括总分机中的信号发送及信号接收电路以及总机中的专用微型机、分机中的专用单片微信机等。专用微型机还完成其他功能及控制作用。
    • 通话部分：总机的送受话放大器和踏键、分机的话机。

2.1.2 选叫信号：怎么精准 “喊到” 目标分机？

选叫信号是 “数字调频信号”，可以理解为 “带编码的声波”，规则如下：

  • 编码结构：先导码（标志码，比如 0CAH）+ 分机码（比如单呼用 C₈⁴组合码）；
  • 频率规则：“1” 对应 1300Hz，“0” 对应 2000Hz，信号传输速度 100bit/s；
  • 特点：抗干扰强，能在长距离线路上稳定传输。

2.2 硬件构成

2.2.1 系统整体构成

  • 核心设备：总机（含控制盘、整配盘、通话盘、电源盘、告警盘）与分机，总机需搭配选叫箱才能正常工作。
  • 功能划分：选叫部分（完成总机对分机的选叫、检测及分机摘 / 放机信号处理，含信号发送 / 接收电路、专用微机）和通话部分（含总机送 / 受话放大器、踏键及分机话机）。

2.2.2 总机核心硬件

  • 控制盘（专用微型机）：双处理机结构（8085A 主机 + 8748 从机），主机负责编码、译码、功能控制，从机负责调制解调；核心芯片含程序存储器（2732）、数据存储器接口（8155）、键盘 / 显示接口（8279-5）、台间联络接口（8251A）等。
  • 整配盘：实现阻抗匹配、二 / 四线转换、信号放大及发送 / 接收信号转换，适配不同线路特性（铁线、铜线、电缆）。
  • 通话盘：含送话放大器（TA7668AP）和受话放大器（TA7240AP），具备自动电平调整（AGC）、高频提升、静噪功能，保证通话音质。

2.2.3 分机硬件构成

  • 核心：专用单片机（80C39/80C48）+ EPROM（27C16）+ 三态锁存器（74HC373），实现信号接收、解调、响应及发码功能。
  • 关键接口：通过 I/O 口实现用户监测、振铃控制、回铃信号发送、摘 / 放机信号处理，支持本地地址编码设置。

2.3 软件结构

1. 软件设计原则

  • 主机软件：按中断方式设计，优先级为 RST7.5（从机通信）＞RST6.5（台间联络）＞RST5.5（键盘 / 显示）。
  • 从机软件：按查询方式设计，核心完成软件调制解调及与主机的数据交换。

2. 核心软件模块

  • 主机软件：初始化模块（设置计数器、标志位、中断入口地址、清显示、开中断）、键盘分析模块（按键编码读取、合法性判断、功能映射）、选叫分机模块（分机码计算、标志设置、发码控制）、RST7.5 中断服务模块（处理发送 / 接收 / 定时 / 自检中断）。
  • 从机软件：调制模块（将二进制码转换为 FSK 信号，添加起始位 / 结束位）、解调模块（通过过零检测还原二进制码，去掉冗余位）、定时控制模块（发码后等待回执信号的定时）。

3. 核心功能实现流程

  • 单呼流程：按键触发→编码→发先导码 + 分机码→等待回铃码→收到回铃码点亮指示灯，未收到则重发 3 次→故障提示。
  • 全呼流程：按全呼键→发先导码 + 全呼码→等待回铃码→收到回铃码点亮指示灯，未收到则重发 3 次→故障提示。
  • 其他功能流程：依次选叫（逐次呼叫指定分机）、台间联络（通过 8251A 实现串行通信）、自检及分机检测（在线诊断设备状态）。

2.4 系统主要技术指标及分析

1. 传输适配指标

  • 适用线路：4.0mm 铁线（100km 区段）、3.0mm 铜线（400km 区段）、0.9mm 加感电缆等，支持载波遥控通路；传输通路定位衰耗≤22dB（800Hz），最大衰耗≤30dB（800Hz）。
  • 音频性能：远端分机讲话扬声器输出功率≥100mW（20dB），近端≤350mW（25dB）；300Hz 与 3400Hz 电平差≤10dB，杂音防卫度≥33dB。

2. 信号传输指标

  • 选叫信号：FSK 调制，传号频率 1300Hz，空号频率 2000Hz，传信率 100bit/s，偏移率 7，采用异步传输；选叫码由先导码（OCAH）+ 分机码组成，有效位 16 位（偶校验）。
  • 电平设计：发送电平（52±2）dB，接收灵敏度 - 36dB（1400Ω 阻抗下 20mV），确保恶劣环境下可靠接收。

3. 阻抗匹配指标

  • 总机输入阻抗：适配不同线路（600±15%Ω/1400±10%Ω，800Hz），减少信号损耗。
  • 分机输入阻抗：未摘机时（2000Hz）≥30kΩ，摘机时（800Hz）≥18kΩ，降低传输衰耗。

4. 其他关键指标

  • 选叫时长：单次选叫（含等待回铃码）约 620ms，三次重发最长 2320ms；分机耗电量：平时≤10mA，响铃时≤100mA。
  • 功能扩展：选叫号码可扩充至 70 个，预留接口支持功能升级。

数位DP

数位是指把一个数字按照个、十、百、千等等一位一位地拆开，关注它每一位上的数字。如果拆的是十进制数，那么每一位数字都是 0~9，其他进制可类比十进制。

数位 DP：用来解决一类特定问题，这种问题比较好辨认，一般具有这几个特征：

  1. 要求统计满足一定条件的数的数量（即，最终目的为计数）；
  2. 这些条件经过转化后可以使用「数位」的思想去理解和判断；
  3. 输入会提供一个数字区间（有时也只提供上界）来作为统计的限制；
  4. 上界很大（比如 1018），暴力枚举验证会超时。

基本原理

考虑人类计数的方式，最朴素的计数就是从小到大开始依次加一。但我们发现对于位数比较多的数，这样的过程中有许多重复的部分。例如，从 7000 数到 7999、从 8000 数到 8999、和从 9000 数到 9999 的过程非常相似，它们都是后三位从 000 变到 999，不一样的地方只有千位这一位，所以我们可以把这些过程归并起来，将这些过程中产生的计数答案也都存在一个通用的数组里。此数组根据题目具体要求设置状态，用递推或 DP 的方式进行状态转移。

数位 DP 中通常会利用常规计数问题技巧，比如把一个区间内的答案拆成两部分相减（即 ans[𝑙,𝑟] =ans[0,𝑟] −ans[0,𝑙−1]）

那么有了通用答案数组，接下来就是统计答案。统计答案可以选择记忆化搜索，也可以选择循环迭代递推。为了不重不漏地统计所有不超过上限的答案，要从高到低枚举每一位，再考虑每一位都可以填哪些数字，最后利用通用答案数组统计答案。

随着光传送网向超高速、超大容量的方向发展，网络的生存能力、网络的保护倒换和恢复问题成为网络的关键问题，而光开关在光层的保护倒换对业务的保护和恢复起到了更为重要的作用。
未来的光传送网是能支持多业务的透明光传送平台,要求对各种速率业务能透明传送;同时,随着业务需求的急剧增长,骨干网业务交换容量也急剧增长。因此,光开关的交换矩阵的大小也要不断提高。同时由于IP业务的急剧增长,要求未来的光传送网能支持光分组交换业务,未来的核心路由器能在光层交换。这样,就对光开关的交换速度提出了更高的要求(纳秒数量级)。总之,大容量、高速交换、透明、低损耗的光开关将在光网络发展中起到更为重要的作用。

2.1 光开关的应用范围

光开关(OS,Optical Swiching)是一种具有一个或多个可选择的传输窗口、可对光传输线路或集成光路中的光信号进行相互转换或逻辑操作的器件。
光开关的基本形式是2X2，即入端和出端各有两条光纤,可以完成两种连接状态:平行连接和交叉连接。如图2-1所示。

图2-1 光开关的平行连接和交叉连接
较大型的空分光交换单元可以由基本的2X2光开关以及相应的1X2光开关级联、组合构成。
光开关在光网络中起到十分重要的作用,在光波分复用传输系统中,光开关可用于波长适配、再生和时钟提取;在光时分复用(Optical Time Division Multiplex,OTDM)系统中,光开关可用于解复用;在全光交换系统中,光开关是光交叉连接的关键器件,也是波长变换的重要器件。根据光开关的输入和输出端口数,可分为1X1.1X2.1XN、2X2.2XN.MXN等多种,它们在不同场合中有不同用途。
应用范围如下:

  1. 光网络的保护倒换系统
    这种保护通常只需要最简单的1X2光开关
  2. 光线测试中的光源控制
    1x2光开关在光线测试技术中主要应用于控制光源的接通和切断
  3. 网络性能的实时监控系统
    在远端光纤测试点,通过1XN多路光开关把多根光纤接到光时域反射仪上,进行实时网络监控,通过计算机控制光开关倒换顺序和时间,实现对所有光纤的检测,并将检测结果传回网络控制中心,一旦发现某一路出现问题,可在网管中心直接进行处理.
  4. 光器件的测试
    1XN光开关
  5. 构建OXC设备的交换核心
    OXC主要应用于骨干网，对不同子网的业务进行汇聚和交换。光开关的使用使OXC具有动态配置交换业务和支持保护倒换功能,在光层支持波长路由的配置和动态选路。由于OXC主要用于高速大容量密集波分复用光骨干网上,因此要求光开关具有透明性,高速,大容量和多粒度交换的特点。
  6. 光分插复用
    光分插复用(OADM)主要应用于环形的城域网中,实现单个波长和多个波长从光路自由上/下话路。光开关矩阵是OADM的关键部分,用光开关OADM可以通过软件控制动态上/下任意波长,这样将增加网络配置的灵活性。
  7. 光传感系统
    1XN光开关还可应用于点传感系统,实现空分复用和时分复用。
  8. 光学测试
    1XN和NX1光开关还可组成光学扫描镜阵列。

2.2 光开关的分类和主要性能参数

按工作原理分类:机械式/非机械式(波导型)

利用光自由度的方式:空分型/时分型/自由空间型

交换介质:自由空间/波导/全光/其他类型

常用的光开关有以下几种:MEMS光开关、热光效应光开关、声光开关、液晶光开关、喷墨气泡光开关、全息光开关、液体光栅光开关、SOA光开关等

主要性能参数

  1. 交换矩阵的大小
    光开关交换矩阵的大小反映了光开关的交换能力。光开关处于网络不同位置，对其交换矩阵大小要求也不同。随着通信业务需求的急剧增长,光开关的交换能力也需要大大提高,如在骨干网上要有超过1000X1000的交换容量。对于大交换容量的光开关,可以通过较多的小光开关叠加而成。
  2. 交换速度
    交换速度是衡量光开关性能的重要指标。交换速度有两个重要的量级,当从一个端口到另一个端口的交换时间达到几毫秒时,对因故障而重新选择路由来说,时间已经够了。如对同步数字系列/同步光网络(SDH/SONET)来说,当因故障而重新选路时,50ms的交换时间几乎可以使上层感觉不到。当交换时间达到纳秒量级时,可以支持光互联网的分组交换。这对于实现光互联网是十分重要的。
  3. 损耗
    当光信号通过光开关时,将伴随着能量损耗。依据功率预算设计网络时,光开关及其级联对网络性能的影响很大。损耗和干扰将影响到功率预算。光开关损耗产生的原因主要有两个:光纤,以及光开关端口耦合时的损耗,以及光开关自身材料对光信号产生的损耗。一般来说，自由空间交换的光开关的损耗低于波导交换的光开关的损耗。如液晶光开关和MEMS光开关的损耗较低,大约为1~2dB。而铌酸锂和固体光开关的损耗较大,大约为4dB左右。损耗特性影响到了光开关的级联,限制了光开关的扩容能力。
  4. 交换粒度
    不同的光网络业务,对交换的需求和光域内使用的交换粒度的需求也有所不同。交换粒度可分为3类:波长交换、波长组交换和光纤交换。交换粒度反映了光开关交换业务的灵活性。这对于考虑网络的各种业务需求、网络保护和恢复具有重要意义。
  5. 无阻塞特性
    无阻塞特性是指光开关的任一输入端能在任意时刻将光波输出到任意输出端的特性。大型或级联光开关的阻塞特性更为明显。光开关要求具有严格无阻塞特性。
  6. 升级能力
    基于不同原理和技术的光开关,其升级能力也不同。一些技术允许运营商根据需要随时增加光开关的容量。很多开关结构可容易地升级为8X8或32X32,但却不能升级到成百或上千的端口,因此只能用于构建OADM或城域网的OXC,而不适用于骨干网上。
  7. 可靠性
    光开关要求具有良好的稳定性和可靠性。在某些极端情况下,光开关可能需要完成几千几万次的频繁动作。有些情况(如保护倒换),光开关倒换的次数可能很少,此时,维持光开关的状态是更主要的因素。如喷墨气泡光开关,如何保持其气泡的状态是需要考虑的问题。

很多因素会影响光开关的性能,如光开关之间的串扰、隔离度、消光比等都是影响网络性能的重要因素。当光开关进行级联时,这些参数将影响网络性能。光开关要求对速率和业务类型保持透明。

2.3 MEMS光开关

传统的机械式光开关是依靠光纤或光学元件(透镜或反射镜)的移动使光路发生改变，将光直接送到或反射到输出端。机械式光开关虽然体积偏大,开关时间偏长,不适合用于大规模开关矩阵及OXC应用,但其插入损耗低、串扰小、重复性好、与使用的光波长和偏振态无关且价格便宜。低端口1X2、2X2机械式光开关是用户的最佳选择。即使是NXN(N>2)的阵列，光开关也可以由1X2、2X2开关组装而成。在全光网络的初级实验阶段,机械式光开关仍有不可替代的作用。
分类:

  2. 采用磁保持的1X2、2X2等机械式光开关。

2.3.2 微电子机械系统光开关

微电子机械系统(MicroElectro-Mechanical System,MEMS)光开关，是半导体微细加工技术与微光学和微机械技术相结合产生的一个新型微机-电-光一体化的开关,它具有光信号的数据格式透明、与偏振无关、差损小、可靠性好、速度快、容易集成的优点,成为大容量交换光网络开关发展的主流方向。
MEMS光开关是在硅晶上刻出若干微小的镜片,通过静电力或电磁力的作用,使可以活动的微镜产生升降,旋转或移动,从而改变输入光的传播方向以实现光路通断的功能。MEMS光开关较其他光开关具有明显优势:开关时间一般在数毫秒量级;使用了IC制造技术,体积小、集成度高;工作方式与光信号的格式、协议、波长、传输方向、偏振方向、调制方式均无关,可以处理任意波长的光信号;同时具备了机械式光开关的低插损、低串扰、低偏振敏感性、高消光比和波导开关的高开关速度、小体积、易于大规模集成的优点。
按功能实现方法分类:

  • 光路遮挡型
  • 移动光纤对接型
  • 微镜反射型
    微镜反射型MEMS光开关方便集成和控制,易于组成光开关阵列,是MEMS光开关研究的重点,可分为二维MEMS光开关和三维MEMS光开关,并已提出一维MEMS光开关的概念。
    所谓二维是指活动微镜和光纤位于同一平面上,且活动微镜在任一给定时刻要么处于开态,要么处于关态。在这种方式中,活动微镜阵列与N根输入光纤和N根输出光纤相连。对一个NXN光开关矩阵而言,所需的活动微镜数为N**2。因此,这种方式也称为N结构方案。

1.2 WDM技术的优点

1.2.1 WDM原理

单模光纤并不仅仅是在1.31μm和1.55μm两个独立波长上是低损耗的,而是存在两个低损耗窗口,其总宽度约200nm,所提供的带宽达27THz。因此人们设想:如果在这两个窗口上以适当的波长间隔△λ选取多个波长做载波,然后通过一个器件把它们合在一起传输,到达接收端后,再通过另一个器件将它们分离开来,这样,就可以在不提高单信道速率的情况下,使光纤中的传输容量成倍增加,从而降低每一通路的成本,避免电子瓶颈的限制。这就是光波分复用技术。

图1-1 普通单模光纤的衰减随波长变化示意图
所谓WDM(Wavelength Division Multiplexing)就是为充分利用单模光纤低损耗区的巨大带宽资源,采用光波分复用器(合波器),在发送端将多个不同波长的光载波合并起来并送入一根光纤进行传输,在接收端,再由光解复用器(分波器)将这些不同波长承载不同信号的光载波分开的复用方式。

图1-2 WDM系统原理方框图
从图1-2中可以看出,在发送端由光发送机TX.分别发出标称波长为λ的光信号,每个光通道可分别承载不同类型或速率的信号,如2.5Gbit/s或10Gbit/s的SDH信号或其他业务信号,然后由光波分复用器把这些复用光信号合并为一束光波输入到光纤中进行传输;在接收端用光解复用器把不同光信号分解开,分别输入到相应的光接收机RX中.
WDM系统
关键组成= 合/分波器 + 光放大器 + 光源

  • 合/分波器
    • 插入衰耗低
    • 具有良好的带通特性(通带平坦、过渡带陡峭、阻带防卫度高)
    • 温度稳定性好(中心工作波长随环境温度变化小)
    • 复用通道数多
    • 具有较高分辨率和几何尺寸小等。
  • 光放大器
    • 高增益、宽带宽、低噪声
  • 光源
    • 能发射稳定的标称光波长、高色散容限、低啁啾

1.2.2 特点

  1. 充分利用光纤的低损耗带宽,实现超大容量传输
  2. 节约光纤资源,降低成本
  3. 可实现单根光纤双向传输
  4. 各通道透明传输、平滑升级扩容
  5. 可利用EDFA实现超长距离传输
  6. 对光纤的色散并无过高要求
  7. 可组成全光网络

1.3 光通信网



graph LR
    A[电网络] --> B[光电网络] -->C[全光网络]

由于光信号固有的模拟特性和光器件的水平,人们暂时放下了全光网的追求,转而用“光传送网”来代替,即子网内全光透明,而在子网边界处采用光/电/光技术。全光网已被ITU-T定义为光传送网(Optical Transport Network,OTN)。光传送网是在现有的传送网中加入光层,提供光交叉连接和分插复用功能,提供有关客户层信号的传送、复用、选路、管理、监控和生存性功能。
光交换逐步取代电交换,网络正在利用OADM、OXC构建WDM光网络。

1.5 自动光交换网络

自动光交换网络(Automatic Switched Optical Network,ASON)在传统的静态光网络中引入动态交换和智能控制能力，从而使传送网实现从承载网向业务网的演进。
在这种情形下,光传送网向智能化方向发展可谓是大势所趋。智能光网络(ION)不仅能够对网络、资源、业务流量进行更加智能化的配置、管理,根据数据流量类型实现数据业务的分类,并且具有SDH网络一样的保护、倒换能力。为了有效地解决现有网络所遇到的问题和为网络增加智能,一种新型的网络体系应运而生,这就是自动交换传送网(ASTN),其中以OTN为基础的ASTN又称自动交换光网络(ASON)。
ASTN/ASON的提出被誉为传送网技术的重大突破,其核心在于引入控制技术实现自动交换，将推动传输网络和交换网络的统一,实现基础网络的智能化。ASON的重要标志是实现了网络的分布式智能,即网元的智能化,具体体现为依靠网元实现网络拓扑发现、路由计算、链路自动配置、路径的管理和控制、业务的保护和恢复等。通过引入分布式智能，一方面连接的建立采用分布式动态方式,各节点自主执行信令、路由和资源分配;另一方面ASON 设备可自动发现物理上、逻辑上与之有关系的网元;此外,在网络出现故障时,ASON还可利用分布式算法快速执行保护恢复等。
ASON比SDH保护方式更强,SDH是基于单个环进行保护,而ASON则是基于网络进行保护。例如,一个4点组成的网状网,每点到其他3点均有直接连接,用SDH实现保护很麻烦,必须建立若干个环网,而ASON则不用,断掉任意一条路由,都可以自动切换至其他路由。
